# 🧠 Ejercicios de Lógica de Programación

Repositorio personal para practicar lógica de programación, desde lo más básico hasta retos que te hacen pensar en serio.

## 📌 Objetivo

- Reforzar lógica antes de saltar a frameworks
- Practicar sintaxis del lenguaje (TypeScript / Python)
- Tener un registro de progreso visible

## 🟢 Nivel Básico

Variables, condicionales, bucles simples, operaciones básicas.

- [x] 01. Suma de dos números — Pide dos números y muestra su suma.
- [x] 02. Par o Impar — Determina si un número ingresado es par o impar.
- [x] 03. Mayor de tres números — Dados tres números, indica cuál es el mayor (sin usar max()).
- [x] 04. Tabla de multiplicar — Muestra la tabla de multiplicar de un número del 1 al 10.
- [x] 05. Suma del 1 al 100 — Calcula la suma de todos los números del 1 al 100 usando un bucle.
- [x] 06. Factorial — Calcula el factorial de un número N (ej: 5! = 120).
- [x] 07. Contador de vocales — Pide una palabra y cuenta cuántas vocales tiene.
- [x] 08. Promedio — Pide N números y calcula su promedio.
- [x] 09. Número invertido — Dado un número (ej: 1234), muéstralo invertido (4321).
- [ ] 10. FizzBuzz — Imprime del 1 al 100, pero:
      - Divisible por 3 → "Fizz"
      - Divisible por 5 → "Buzz"
      - Divisible por ambos → "FizzBuzz"
- [ ] 11. Calculadora básica — Suma, resta, multiplicación y división usando funciones separadas.
- [ ] 12. Validar contraseña — Mínimo 8 caracteres, una mayúscula, una minúscula y un número.

---

## 🟡 Nivel Medio

Strings, arrays, matrices, algoritmos clásicos de ordenamiento y búsqueda.

- [ ] 13. Palíndromo — Verifica si una palabra o frase se lee igual al derecho y al revés (ignora espacios y mayúsculas).
- [ ] 14. Números primos — Muestra todos los números primos entre 1 y N.
- [ ] 15. Serie Fibonacci — Imprime los primeros N números de la serie (0, 1, 1, 2, 3, 5, 8...).
- [ ] 16. Ordenamiento burbuja — Implementa el algoritmo de ordenamiento burbuja.
- [ ] 17. Búsqueda binaria — Dado un array ordenado, busca un número usando búsqueda binaria.
- [ ] 18. Eliminar duplicados — Dado un array, elimina los elementos repetidos (sin set()).
- [ ] 19. Segundo mayor — Encuentra el segundo número más grande de un array.
- [ ] 20. Matriz transpuesta — Dada una matriz NxM, genera su transpuesta.
- [ ] 21. Pirámide de asteriscos
         *
        ***
       *****
      *******
- [ ] 22. Anagramas — Verifica si dos palabras son anagramas.
- [ ] 23. Números perfectos — Encuentra números perfectos hasta N (ej: 6 = 1+2+3).
- [ ] 24. Conversión de bases — Convierte un número decimal a binario (sin funciones integradas).

---

## 🔴 Nivel Difícil

Recursión, backtracking, algoritmos avanzados, parsing y problemas clásicos de entrevista.

- [ ] 25. Torres de Hanoi — Resuelve el problema con recursión para N discos.
- [ ] 26. Merge Sort — Implementa el algoritmo de ordenamiento por mezcla.
- [ ] 27. Quick Sort — Implementa el algoritmo de ordenamiento rápido.
- [ ] 28. N-Reinas — Coloca N reinas en un tablero NxN sin que se ataquen (backtracking).
- [ ] 29. Sudoku Solver — Resuelve un Sudoku 9x9 con backtracking.
- [ ] 30. Laberinto — Encuentra la salida de un laberinto (BFS o DFS).
- [ ] 31. Calculadora con paréntesis — Evalúa expresiones tipo "2 + 3 * (4 - 1)" (parser).
- [ ] 32. Conversor de números romanos — Convierte de decimal ↔ romano.
- [ ] 33. Permutaciones y subconjuntos — Dado un array, genera todas las permutaciones y todos los subconjuntos.
- [ ] 34. Detección de ciclos — Dada una lista enlazada, detecta si tiene un ciclo.
- [ ] 35. Subsecuencia común más larga (LCS) — Programa dinámico clásico.
